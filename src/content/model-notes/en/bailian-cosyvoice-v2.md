## Overview
Model Studio CosyVoice v2 provides bidirectional streaming synthesis with low first-packet latency. Text is synthesized as it arrives, with Chinese, English, preset voices, and voice cloning.

## Use cases
- Voice conversations and live announcements
- Voice assistants connected to streaming LLM output
- Interactive live-stream voiceovers

## Languages and capabilities
- Languages: Chinese and English
- Bidirectional streaming, preset voices, and voice cloning

## Usage tips
- For more languages or higher quality, choose v3 Plus / v3.5.
- Requires a Model Studio API Key.
