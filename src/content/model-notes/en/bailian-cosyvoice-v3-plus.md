## Overview
Model Studio CosyVoice v3 Plus offers high-quality multilingual streaming synthesis with preset voices, voice cloning, and voice design.

## Use cases
- High-quality multilingual voiceovers
- Clone a specific voice for ongoing content production
- Design a new voice from a description

## Languages and capabilities
- Multilingual
- Streaming synthesis, voice cloning, and voice design

## Usage tips
- For lower costs or interactive latency, consider v3.5 Flash.
- Requires a Model Studio API Key.
