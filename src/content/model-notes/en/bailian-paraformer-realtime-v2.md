## Overview
Model Studio Paraformer Realtime v2 targets live streams and meetings, supporting Chinese dialects, English, Japanese, Korean, and other languages with configurable hotwords.

## Use cases
- Live-stream captions
- Multilingual meeting notes
- Domain-specific applications needing terminology hotwords

## Languages and capabilities
- Chinese (including dialects), English, Japanese, Korean, and more
- Streaming recognition, timestamps, and hotwords

## Usage tips
- For telephone audio, choose the 8K v2 version.
- Requires a Model Studio API Key.
