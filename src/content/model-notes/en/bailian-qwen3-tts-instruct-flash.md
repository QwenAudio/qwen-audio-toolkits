## Overview
Qwen3 TTS Instruct Flash on Alibaba Cloud Model Studio is a low-latency TTS model that supports natural-language instructions for controlling emotion, style, and pacing, making it ideal for expressive dubbing and character voices.

## Use cases
- Emotional narration, advertising voiceovers, and short-form dubbing
- Voice-assistant replies with specific tones (gentle, excited, serious, etc.)
- Multilingual content production

## Languages and capabilities
- Chinese and multiple languages; 24 kHz output
- Preset and custom voices
- Natural-language style control via the instruction parameter

## Usage tips
- Use clear, specific instructions for more consistent stylistic results.
- Requires a Model Studio API Key; billed by character.
