## Overview
Model Studio FunASR Flash 8K Realtime is a real-time Chinese recognition model optimized for 8 kHz audio such as phone support and voicemail.

## Use cases
- Real-time call-center quality monitoring
- Streaming transcription of phone recordings
- Voicemail to text

## Languages and capabilities
- Language: Chinese
- 8 kHz streaming recognition and timestamps

## Usage tips
- For 16 kHz microphone or meeting audio, use the non-8K version.
- Requires a Model Studio API Key.
