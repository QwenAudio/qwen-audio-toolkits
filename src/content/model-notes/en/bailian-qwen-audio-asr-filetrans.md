## Overview
Model Studio Qwen-Audio 3.0 ASR Flash Filetrans provides asynchronous transcription for meetings, interviews, and long recordings. Local audio is uploaded to temporary storage before full timestamped results are returned.

## Use cases
- Hours-long meetings, lectures, and interviews
- Captions needing complete timestamps
- Non-real-time batch file transcription

## Languages and capabilities
- Multilingual
- File transcription and timestamps; up to about 12 hours per file

## Usage tips
- Asynchronous tasks require waiting for processing after submission.
- ASR Flash is faster for clips under 5 minutes.
