## Overview
Model Studio CosyVoice v3.5 Plus is designed for high-quality voice cloning and voice design, with instructions to control emotion and style.

## Use cases
- Premium audiobooks and film dubbing
- High-fidelity voice cloning
- Content requiring precise emotional control

## Languages and capabilities
- Multilingual
- Streaming synthesis, voice cloning, voice design, and instruction control

## Usage tips
- Use Plus when quality is the priority; use the same-generation Flash for real-time interaction.
- Requires a Model Studio API Key.
