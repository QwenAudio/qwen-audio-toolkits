## Overview
Model Studio Qwen3.7 Plus is Qwen's flagship Plus model, with enhanced reasoning, coding, and agent capabilities for high-quality voice assistants and complex tasks.

## Use cases
- Structure complex meeting notes and extract decisions
- Voice agents with multi-step reasoning
- High-quality conversations and content generation

## Languages and capabilities
- Multilingual text generation
- 1M context, complex reasoning, and tool calling

## Usage tips

- Requires a Model Studio API Key; billed by token.
