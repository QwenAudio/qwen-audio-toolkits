## Overview
Model Studio Paraformer Realtime 8K v2 is a real-time Chinese recognition model optimized for 8 kHz telephone audio.

## Use cases
- Live phone-support transcription
- Stream processing of call-center recordings
- Telephone meeting notes

## Languages and capabilities
- Language: Chinese
- 8 kHz streaming recognition and timestamps

## Usage tips
- For non-telephone audio, use Paraformer Realtime v2.
- Requires a Model Studio API Key.
