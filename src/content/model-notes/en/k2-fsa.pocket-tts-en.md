## Overview
Kyutai's PocketTTS is a lightweight English zero-shot synthesis model. Clone a voice from reference audio without entering a transcript.

## Use cases
- English voice cloning
- Quickly preview different voices
- English voiceovers on low-spec devices

## Languages and capabilities
- Language: English
- Zero-shot voice cloning without reference text

## Usage tips
- Use clean reference audio with one speaker.
- For Chinese cloning, use ZipVoice or CosyVoice.
