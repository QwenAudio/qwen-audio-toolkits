## Overview
Qwen Audio 3.0 TTS Flash on Model Studio offers low-latency multilingual synthesis, balancing speed and naturalness with preset and custom voices.

## Use cases
- Narration, content production, and batch voiceovers
- Voice assistant responses
- Interactive applications requiring fast speech output

## Languages and capabilities
- Chinese and multiple languages; 24 kHz output
- Preset + custom voices

## Usage tips
- For higher quality or voice cloning, choose TTS Plus.
- Requires a Model Studio API Key; billed by character.
