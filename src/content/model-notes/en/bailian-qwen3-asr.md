## Overview
Model Studio Qwen3 ASR Flash offers fast recognition for Mandarin, dialects, and multilingual audio, processing recordings and local audio files directly.

## Use cases
- Fast transcription of short clips
- Mixed dialect and multilingual content
- Batch processing with automatic language detection

## Languages and capabilities
- Mandarin, multiple dialects, and multiple languages
- Automatic language detection

## Usage tips
- For recordings longer than a few minutes, use asynchronous Filetrans transcription.
- Requires a Model Studio API Key.
