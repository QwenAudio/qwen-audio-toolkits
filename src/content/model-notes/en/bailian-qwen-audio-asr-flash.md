## Overview
Model Studio Qwen-Audio 3.0 ASR Flash provides fast recognition for short clips, with local audio, language hints, context enhancement, and sentence and word timestamps.

## Use cases
- Instant transcription of voice messages and short recordings
- Improve accuracy with hints when the language is known
- Enhance recognition with context such as terminology and preceding text

## Languages and capabilities
- Multilingual
- Sentence / word timestamps; up to about 5 minutes per request

## Usage tips
- Use Filetrans for audio longer than 5 minutes.
- Requires a Model Studio API Key.
