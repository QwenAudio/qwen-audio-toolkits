## 简介
阿里云百炼的 Fun Audio Denoising 云端降噪服务，面向录音、识别预处理和声音复刻素材，支持长音频与多种常用格式。

## 适用场景
- 声音复刻前的参考音频清理
- 会议、访谈长录音降噪
- 本机算力不足时的批量处理

## 语言与能力
- 与语言无关
- 文件处理，单次最长约 2 小时

## 使用建议
- 音频需上传至云端处理，隐私敏感素材请使用本地 DeepFilterNet3 / ZipEnhancer
- 按调用计费，请在 Provider 中配置百炼 API Key

## 来源与许可
- 服务商：阿里云百炼 · 模型 ID：fun-audio-denoising
- 需要 Bailian API 访问权限
