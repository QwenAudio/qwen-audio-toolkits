# 模型说明

每个模型一份 Markdown，文件名为模型 id（本地模型见 `src-tauri/src/plugins.rs` 的内置清单，
云端模型见 `catalog/model-catalog.json` 的 `apiModels`）。扩展页「模型介绍」区块会渲染
对应文件；没有文件的模型回退到清单里的一句话 `description`。列表卡片始终使用一句话描述。

统一模板：

```markdown
## 简介
一两句话说明模型是什么、定位如何。

## 适用场景
- 场景 1
- 场景 2

## 语言与能力
- 支持的语言
- 关键能力（流式 / 时间戳 / 克隆 …）

## 使用建议
- 精度 / 体积选择
- 与其他模型的取舍、配套组件

## 来源与许可
- 发布方 · 许可 · 运行时 · 精度 / 体积 / 版本
```
