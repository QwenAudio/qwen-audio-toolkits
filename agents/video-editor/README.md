# 视频剪辑 Agent

这个项目是 Toolkits 的独立本地 Agent。对话区只接收素材和剪辑意图；视频预览、剪辑说明、时间线和媒体信息由右侧结果栏承载，不再提供第二套“告诉我怎么剪”的表单或文本模型选择器。

- 可以先描述目标，Agent 会说明还缺少什么素材或剪辑信息。
- 上传视频后，明确写出“保留 00:10–00:45”或“截取 10–45 秒”时，会用本机 FFmpeg 生成可预览的 MP4。
- 其他需求会生成审阅预览和待补齐的剪辑计划；语音识别、字幕和复杂时间线在后续 Agent 能力接入后执行。
- 不联网、不要求文本模型。安装 FFmpeg/FFprobe 可读取媒体信息并导出明确的截取结果。

本 Agent 接收的视频和返回的 MP4 均受 SDK 单文件 32 MiB 限制，适合原型和短视频；生产发布前应把大文件传输改为本地文件句柄或分块协议。
