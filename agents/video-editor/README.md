# 视频剪辑 Agent

这个项目是 Toolkits 的独立本地 Agent。对话区只接收素材和剪辑意图；视频预览、剪辑说明、时间线、字幕文稿和媒体信息由右侧结果栏承载，不再提供第二套“告诉我怎么剪”的表单或文本模型选择器。

- 可以先描述目标，Agent 会说明还缺少什么素材或剪辑信息。
- 上传视频后，明确写出“保留 00:10–00:45”或“截取 10–45 秒”时，会用本机 FFmpeg 生成可预览的 MP4。
- 说“加字幕”“生成中文字幕”或“add English captions”时，Agent 会用本机 Whisper 转写，生成 SRT 并将字幕烧录到右侧的 MP4 预览；右侧同时展示可核对的字幕文稿。
- FFmpeg 不带 `subtitles` 滤镜时，macOS 会用随 Agent 发布的 Swift 渲染器生成字幕画面后再合成视频。其他平台需要 FFmpeg 带字幕滤镜。
- 没有视频音轨时无法生成字幕；未安装 Whisper 时，Agent 会在对话中说明需要的本机语音识别能力。Whisper 的 `base` 模型首次使用会下载并缓存，之后可离线使用。

本 Agent 接收的视频和返回的 MP4 均受 SDK 单文件 32 MiB 限制，适合原型和短视频；生产发布前应把大文件传输改为本地文件句柄或分块协议。
