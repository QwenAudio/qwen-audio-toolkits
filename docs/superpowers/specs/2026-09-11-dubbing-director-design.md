# 视频配音导演与预览工作室设计文档

**日期：** 2026-09-11  
**状态：** 待实现  
**关联功能：** 视频配音（video-dubbing）

## 1. 背景与目标

当前视频配音提供「翻译原声」「修改原稿」「使用新文案」三种模式，但用户难以预期输出效果、看不到中间过程、也无法逐句干预。与此同时，百炼平台已上线支持指令化情绪和音色控制的 TTS 模型，项目尚未接入。

### 1.1 目标

把视频配音从「参数配置」升级为「导演式创作」：

1. 用户上传视频后，AI 自动拆分对白并生成配音剧本。
2. 每句配音可指定情绪、风格、音色。
3. 整个过程通过流水线进度看板实时可见。
4. 生成过程中即可边生成边预览、逐句修改。
5. 最终导出配音视频 + 新字幕 + 可选独立音轨。

### 1.2 成功标准

- 30 秒短视频可在 3 分钟内完成导出。
- 用户能清楚看到当前在哪一步、处理了第几句。
- 预览工作室支持原片/配音版 side-by-side 对比。
- 「翻译原声」任务完成率较当前版本提升。

## 2. 范围

### 2.1 v1 包含

- 配音剧本自动生成（分句 + 译/改/重写决策 + 情绪标注）。
- 6 种情绪预设：激动、平静、严肃、轻松、温柔、有力。
- 音色复刻与虚拟音色设计入口。
- 预览工作室：时间轴、side-by-side 对比、逐句编辑、单句重配。
- 流水线进度看板：8 个步骤状态可视化。
- 导出：配音视频 + 新字幕 + 可选独立音轨。

### 2.2 v1 不包含

- 真正的口型生成/换脸（成本过高）。
- 字级别重配（仅支持整句）。
- 实时直播配音（保留给 v2）。
- 多人声的独立音色分配（v1 默认统一音色）。

## 3. 模型商店更新

### 3.1 补齐 qwen-audio 系列

项目已接入 `qwen-audio-3.0-asr-flash`、`filetrans` 及基于 `fun-asr` 的 streaming。v1 不再新增 qwen-audio ASR。

任务默认 TTS 保持使用现有 `qwen-audio-3.0-tts-flash` / `plus`，作为无情绪指令时的默认音色渲染路径。

### 3.2 新增 qwen3 / qwen 系列模型

| 模型 ID | 能力 | 用途 |
|---|---|---|
| `qwen3-tts-instruct-flash` | 指令控制情绪/风格 TTS | 情绪化配音导演的核心后端 |
| `qwen3-tts-vc-2026-01-22` | 音色复刻 TTS | 用参考音频克隆说话人音色 |
| `qwen-voice-design` | 虚拟音色设计 | 按描述生成角色/风格化音色 |

上述模型通过现有 `bailian-tts` adapter 接入，仅需在 `catalog/model-catalog.json` 增加条目并指定对应 `modelId`。

## 4. 功能设计

### 4.1 配音导演（DubbingDirector）

用户选择配音方式后，进入导演阶段：

1. **提取对白**：ASR 识别原视频台词，按句拆分并保留时间戳。
2. **生成剧本**：LLM 根据配音方式生成每句的「配音稿」，并标注建议情绪。
   - 翻译模式：直译原台词。
   - 改写模式：按用户指令改写，贴合原时长。
   - 新文案模式：使用用户提供的完整文案，按时间轴分配。
3. **情绪与音色决策**：
   - 默认情绪由 LLM 根据上下文推断。
   - 用户可在预览中逐句修改情绪、音色、文案。

### 4.2 情绪化音色控制

- **默认路径**：使用 `qwen-audio-3.0-tts-flash` / `plus` 渲染配音，成本最低。
- **情绪增强路径**：当用户为某句指定情绪或风格时，调用 `qwen3-tts-instruct-flash`，将情绪指令随文本一起传入。
- **音色复刻路径**：用户提供参考音频时，调用 `qwen3-tts-vc-2026-01-22`。
- **虚拟音色路径**：用户输入音色描述时，调用 `qwen-voice-design` 生成音色后再用于 TTS。

### 4.3 预览工作室（PreviewStudio）

界面核心区域：

- **顶部**：总进度条 + 当前高亮步骤。
- **左侧视频**：原片 / 配音版切换，或 side-by-side 并排。
- **右侧时间轴**：每句对白一行，显示：
  - 原台词
  - 配音稿
  - 情绪标签
  - 音色来源
  - 播放按钮
  - 重配按钮
- **底部工具栏**：导出、重置、选择全局音色/情绪。

交互规则：

- 生成过程中，已完成的句子立即出现在时间轴并可播放。
- 用户点击句子可展开编辑：改文案、换情绪、换音色、重生成。
- 修改后仅重跑该句及后续对齐，不重新生成全部。

### 4.4 流水线进度看板

顶部步骤看板展示 8 个阶段及状态：

1. 提取音轨
2. 识别台词
3. 生成配音剧本
4. 分配音色与情绪
5. 生成配音片段
6. 对齐节奏
7. 合成预览
8. 导出成片

每个步骤显示：

- 等待 / 运行中 / 完成 / 失败 图标
- 当前子状态，如「正在生成第 5/12 句配音」
- 失败时支持单步重试
- 运行中支持取消

## 5. 架构

### 5.1 前端组件

- `DubbingDirectorView`：导演主页面，协调整个流程。
- `DubbingProgressBoard`：流水线步骤看板。
- `DubbingScriptPanel`：配音剧本编辑器。
- `PreviewStudio`：预览工作室容器。
- `DubbingTimeline`：逐句时间轴。
- `DubbingLineEditor`：单句编辑弹窗/面板。
- `EmotionPicker`：情绪选择器。
- `VoiceSourcePicker`：音色来源选择器（默认 / 复刻 / 设计 / 上传）。

### 5.2 后端/运行时

复用现有 Harness 能力：

- ASR：`speech.transcribe`（本地或百炼）。
- 文本生成：`text.generate`（用于剧本生成）。
- TTS：`speech.synthesize`（qwen-audio 默认）或百炼 TTS adapter（情绪/复刻/设计）。
- 对齐：现有视频配音节奏对齐逻辑增强，支持停顿处音频伸缩。
- 视频合成：现有视频导出流程。

新增：

- `DubbingPipeline` 状态机，管理 8 个步骤及取消/重试。
- `DubbingScript` 数据结构，保存对白单元、情绪、音色、生成状态。

## 6. 数据流

```
视频上传
  → 提取音轨 / 分离人声
  → ASR 识别台词
  → LLM 生成配音剧本（原台词 + 配音稿 + 情绪 + 音色决策）
  → 用户确认/修改剧本
  → 逐句 TTS（qwen-audio 默认 / qwen3-instruct 情绪 / qwen3-vc 复刻 / qwen-voice-design 设计）
  → 节奏对齐（停顿处伸缩）
  → 合成预览
  → 用户调整
  → 导出最终视频
```

关键状态：

- `DubbingLine`：
  - `id`, `start`, `end`, `originalText`, `dubbedText`
  - `emotion`: 情绪标签
  - `voiceSource`: { kind: 'default' | 'clone' | 'design' | 'upload', reference? }
  - `audioUrl`: 生成后的音频片段
  - `status`: 'pending' | 'generating' | 'done' | 'error'

## 7. 错误处理

- 任一步骤失败时，该步骤标记为失败，其他已完成步骤保留。
- 用户可重试失败步骤（单步重试）。
- TTS 单句失败时，不影响其他句子，失败句显示重试按钮。
- 取消后保留已生成结果，允许用户基于当前状态继续或导出半成品。

## 8. 测试策略

- **单元测试**：`DubbingScript` 状态转换、`DubbingPipeline` 步骤推进。
- **集成测试**：使用 10-30 秒样例视频，跑通完整流水线并检查导出。
- **模型 smoke**：新增模型接入后，验证 `qwen3-tts-instruct-flash`、`qwen3-tts-vc`、`qwen-voice-design` 可正常返回音频 URL。
- **UI 测试**：预览工作室边生成边渲染，确认单句编辑后仅重跑该句。

## 9. 实现阶段

### Phase 1：模型上架

- 在 `catalog/model-catalog.json` 增加：
  - `bailian-qwen3-tts-instruct-flash`
  - `bailian-qwen3-tts-vc`
  - `bailian-qwen-voice-design`
- 验证 adapter 路由正确，跑 smoke test。

### Phase 2：流水线状态机

- 实现 `DubbingPipeline` 和 8 步骤看板 UI。
- 把现有视频配音流程套进状态机，先不带情绪/预览增强。

### Phase 3：配音导演

- 接入 LLM 生成配音剧本。
- 支持翻译 / 改写 / 新文案三种模式的剧本生成。

### Phase 4：情绪化音色与预览工作室

- 接入 `qwen3-tts-instruct-flash` 情绪控制。
- 接入 `qwen3-tts-vc` 和 `qwen-voice-design`。
- 实现预览工作室 UI 和单句编辑。

### Phase 5：导出与调优

- 支持配音视频 + 字幕 + 独立音轨导出。
- 性能调优，确保 30 秒视频 3 分钟内导出。

## 10. 待确认问题

1. `qwen3-tts-instruct-flash` 的 API 参数格式（instruction 字段名、是否支持 streaming）需要接入时验证。
2. `qwen-voice-design` 生成音色后如何持久化音色 ID 并在 TTS 中引用。
3. v1 是否允许用户上传任意参考音频做音色复刻，还是仅支持项目内置样例。
